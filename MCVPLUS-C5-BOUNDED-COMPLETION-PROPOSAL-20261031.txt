## Important incompatibility — resolve before implementation
The exact-name mutable provider namespace cannot be proved by granting the provider directory Modify: directory create/rename rights permit additional names. Validating the provider's normal source strings does not constrain a compromised service token. Existing per-name predicates do not solve this.

Likewise Postgres Modify over its data/config cannot prove immutable configuration inside its own trust domain. Filesystem separation must not be presented as database semantic integrity; mutable configuration must not enable an unreviewed executable/module path.

Therefore the existing combination of directory Modify, current exclusive slot creation/rotation and adversarial exact-name confinement has no ACL-only completion. General ACL support does not fix it.

It must preserve 48 total immutable logical reservations, concurrent exclusivity, crash/restart recovery, bounded logging and failure/halt semantics. This changes the current reservation/rotation implementation and requires explicit contract/build-identity review, not a claim of equivalence. Original sealed packet remains unchanged. Current file-create ledger cannot run against precreated slots unchanged.
